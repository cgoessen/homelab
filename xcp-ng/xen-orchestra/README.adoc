= Xen Orchestra

https://xo.gssn.xyz/[Homepage]

https://xen-orchestra.com/docs/installation.html#from-the-sources[Documentation]

== Prepare
[source,bash]
----
apt install vim certbot build-essential redis-server libpng-dev git python3-minimal libvhdi-utils lvm2 cifs-utils nfs-common ntfs-3g libfuse-dev
----

Create certificates (see certificates]

=== Install node

[source,bash]
----
# get nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash
# install LTS
nvm install 22
# yarn
npm install --global yarn
----

== Build

[source,bash]
----
# clone repo
git clone -b master https://github.com/vatesfr/xen-orchestra
cd xen-orchestra
yarn
# build can be flaky
yarn build
# creat service
yarn global add forever
yarn global add forever-service
# todo rootless run
cd packages/xo-server
forever-service install orchestra -r root -s dist/cli.mjs
----

== Config

With running user
[source,bash]
----
mkdir -p ~/.config/xo-server
cp packages/xo-server/sample.config.toml /etc/xo-server/config.toml
----

== Run

[source,bash]
----
service orchestra start
service orchestra status
----

== Certificates
[sourche,bash]
----
certbot certonly \
  --authenticator dns-infomaniak \
  --server https://acme-v02.api.letsencrypt.org/directory \
  --agree-tos \
  --rsa-key-size 4096 \
  -d xo.gssn.xyz
----
