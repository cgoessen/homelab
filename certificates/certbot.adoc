= certbot

== Create new certificate

`certbot certonly --manual --preferred-challenges=dns --post-hook /my/post/hook --manual-auth-hook ./certbot-auth-hook.sh -m admin@my-domain -d foobar.my-domain`

The hook script will ensure auto-renewal, it relies on dns challenge with aws route 53, it takes some time.

== infomaniak

[source,bash]
----
export DOMAIN=foo@gssn.xyz
certbot certonly --authenticator dns-infomaniak --dns-infomaniak-credentials /root/dns_infomaniak.ini --server  https://acme-v02.api.letsencrypt.org/directory --agree-tos --rsa-key-size 4096 -d ${DOMAIN} --email 'root@gssn.xyz' --no-eff-email --installer nginx
----
