= K0S

https://docs.k0sproject.io/v1.21.2+k0s.1/[documentation]

== Config

Generate default config

[source,bash]
----
k0s config create > k0s.yaml
----

Install controller first

[source,bash]
----
k0s install controller --enable-worker -c /etc/k0s/k0s.yaml
----

Start the controller
[source,bash]
----
k0s start
----

Generate token
Start the controller
[source,bash]
----
k0s token create --role=controller
----

Add nodes


[source,bash]
----
k0s install controller --token-file my-token --enable-worker -c /etc/k0s/k0s.yaml
----
